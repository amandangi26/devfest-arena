# Application Contracts & Types (`src/types`)

This directory documents shared application contracts, schemas, and type definitions using JSDoc.

## Purpose
In a collaborative codebase with multiple developers contributing independent activities, well-defined contracts provide type-safety, interface predictability, and automated contract validation without requiring a heavy transpilation toolchain.

## Key Files
- [activity.js](file:///c:/Workspace/ByteLab/game-arena/src/types/activity.js): Contains the `ActivityManifest` JSDoc schema, `ActivityStatus`, `DevFestTrack` enums, and the `validateActivityManifest` runtime validator.
