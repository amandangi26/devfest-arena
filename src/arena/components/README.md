# Arena Presentation Components (`src/arena/components`)

This directory houses components specifically built for the live auditorium scoreboard and leaderboard dashboard.

## Components
- [ArenaSidebar.jsx](file:///c:/Workspace/ByteLab/game-arena/src/arena/components/ArenaSidebar.jsx): Collapsible challenge activity selector supporting expanded/collapsed desktop modes and responsive mobile stacking.
- [TrackSelector.jsx](file:///c:/Workspace/ByteLab/game-arena/src/arena/components/TrackSelector.jsx): Accessible 3-track selector (Track 1, Track 2, Track 3) with Google brand theme indicators.
- [Podium.jsx](file:///c:/Workspace/ByteLab/game-arena/src/arena/components/Podium.jsx): Prominent visual stage elevating the Top 3 participants, with 1st place as the centerpiece.
- [Leaderboard.jsx](file:///c:/Workspace/ByteLab/game-arena/src/arena/components/Leaderboard.jsx): Projector-ready ranked standings table displaying rank, participant name, points, and completion time.
