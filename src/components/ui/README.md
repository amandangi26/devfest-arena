# Shared UI Primitives (`src/components/ui`)

This directory contains reusable, accessible UI primitives styled strictly in accordance with the DevFest Ranchi 2026 Neo-Brutalist Design System.

## Principles
1. **Physical Tactility:** Every interactive element must feature tactile button mechanics (X/Y translation with equal shadow contraction on hover/active).
2. **Hard Shadows & Black Borders:** Borders are solid black (`2px` – `3.5px`); shadows use pure black (`#000000`) with zero blur.
3. **Palette Adherence:** Utilize Google brand pigments (`#4285F4`, `#EA4335`, `#FBBC05`, `#34A853`) and Ranchi regional earth tones (`#FFFBF0`, `#FFF8E7`, `#0D2818`).

## Components
- [Button.jsx](file:///c:/Workspace/ByteLab/game-arena/src/components/ui/Button.jsx): Tactile button with primary, secondary, success, danger, outline, and ghost variants.
- [Card.jsx](file:///c:/Workspace/ByteLab/game-arena/src/components/ui/Card.jsx): Neo-brutalist card container with configurable surfaces and unblurred shadows.
- [Badge.jsx](file:///c:/Workspace/ByteLab/game-arena/src/components/ui/Badge.jsx): Tag pill with optional pulsing status indicator dot.
