# Shared Application Assets (`src/assets`)

This directory is reserved for global application brand assets and static vectors.

## Rules
- **Global Assets Only:** Only shared event branding, conference mascots, or platform textures belong here.
- **Activity Assets Isolation:** All activity-specific audio, sprite sheets, illustrations, and 3D assets MUST live inside `src/activities/<activity-id>/assets/` to maintain modular boundaries and allow independent code ownership.
